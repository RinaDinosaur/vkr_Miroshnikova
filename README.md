# ВКР: Разработка цифрового решения для профилирования компетенций будущих врачей

Репозиторий для ведения исследовательского проекта и разработки прототипа цифрового решения в рамках выпускной квалификационной работы Мирошниковой Екатерины 640-01

**Цель работы** — создание инструмента (чат-бота) для оценки и профилирования профессиональных компетенций абитуриентов и студентов медицинских вузов на основе результатов социологического исследования.

## Управление проектом
Задачи, этапы разработки и текущий прогресс отслеживаются в Projects.
Код и другие материалы будут добавляться по мере разработки прототипа.
